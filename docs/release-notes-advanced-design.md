# Unreleased — advanced design tools

Feature branch preview: text-aware Boolean operations, curve/warp modifier editing,
letter welding, nested groups with scoped editing, and worker-based arrangement
previews with contour collision checks. Existing browser rendering, laser layers,
controller pipelines and portable browser launchers are retained.

Project archives use schema 2 for local group coordinates; existing schema 1 files
remain readable. Older app versions cannot open schema 2 archives.

This is not a published release. See `advanced-design-implementation.md` for test
results and the remaining acceptance items before promoting the feature branch.
